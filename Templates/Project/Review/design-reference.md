# 图片与模型的设计约定

按 `Context/image-to-print.md` v3填写。选定设计主图与最初灵感图必须分开；未知保留未知，不把AI补充视图当作尺寸来源。

- 项目 / 候选版本：待填写
- 已选设计主图路径及校验值：待填写；主图不能因容易建模而换回最初灵感照片
- 灵感图及用途：待填写；不作为正式外形回退目标
- 机械接口/尺寸来源及保护区：待填写；与外形目标分别管理
- 用户选定依据 / 原话来源：待填写
- 图片性质：概念透视图 / 实拍 / 由实际模型导出的视图（择一）
- 需要保留的3–5项外形特征：待填写
- 关键尺寸与功能边界：数值、单位、来源（实测 / 官方 / 用户目标 / 暂定），待填写
- 辅助图片及用途：待填写；不作为默认工程三视图
- 四套同款三视图：每套正/右/俯；保存四套编号与文件/hash、用户选定的一整套、每格裁剪和一致性检查
- 主要孔洞/筋节点跨视图对应表：待填写；缺失面/推定结构标明
- `Review/design-target.json` 与 `printlab design-check` 结果：待填写

## 实际粗模与后续依据

- 实际源文件 / 网格路径、版本与校验值：待填写
- 同一实际模型导出的对应三视图（默认正 / 右 / 俯），必要背/底/斜视另作内部检查：待填写；必须另与已选主图对照
- 相机与参考图是否匹配：未匹配 / 近似 / 已配准；依据待填写
- 未见面与内部的设计假设：待填写
- 与主图的已知偏差、下一步修改：待填写
- 用户对明显取舍的选择：未要求选择 / 待选择 / 已选择（有真实记录才填写）

详细外观、尺寸及装配检查另用 `design-review.json`。图片约定与外观选择不授权打印。
