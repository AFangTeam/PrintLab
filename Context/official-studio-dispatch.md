# 官方 Bambu Studio 发送

首次使用先读 `docs/PRINTING.md`，核对本机软件版本、语言、机型、材料和发送助手的支持范围。

1. 读取任务交接、当前版本、已有派发回执与设备状态。遇到未决任务先对账。
2. 确认当前模型/切片/材料与用户的打印要求一致，记录当前清板事实。
3. 使用 `printlab studio-copy --help` 从未发送任务生成单盘官方发送包，保存工具路径和文件比对。
4. `printlab approve` 绑定具体文件、设备和材料。保留实际确认时间。
5. 用官方 Studio 打开这份唯一任务名的包，核对切片预览、机型、板型、喷嘴与 AMS 映射。
6. `printlab submit` 预检，通过后 `submit --execute` 预约同一个任务，Agent 在返回的有效窗口内点击一次发送。
7. `printlab reconcile` 读回匹配任务，另外核实实际出料和首层。超时或结果不明时先查询设备。
8. 完成后登记实物反馈，下一盘需要重新取件清板。

工作台“待打印”页通过专用 macOS 发送助手执行时，同样使用这套文件绑定、批准、锁与回执。首次使用者需要为自己的机器构建并授权发送助手。内置能力检查根据实际环境返回可用范围。
