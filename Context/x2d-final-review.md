# 最终制作 Review

模型完成后，在同一次 Review 中核对质量、可靠性和总成本，使用 `Templates/Project/Review/x2d-final-review.md`。

1. 对照已确认外形、接口、握感与表面要求。
2. 核对本机喷嘴、材料、AMS/外挂、板型和切片配置。
3. 比较摆放方向、按颜色/高度分件分盘、支撑接触层与同层换色次数。
4. 评估双喷嘴、异材支撑和局部层高对当前模型的收益。兼容性须有材料依据。
5. 候选实际切片，统计全套时间、主料、支撑、冲刷、换盘与后处理。等人换盘的时间未知时注明。
6. 保存选择理由、来源文件 hash、预计结果与仍需实物检查的部位。

以设备实际支持为准。单喷与双喷的收益需要针对具体任务比较。多喷嘴能力不代表每件作品都适合多材料。
