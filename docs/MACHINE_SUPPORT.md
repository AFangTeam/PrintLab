# 机型与验证范围

本表对应观众版候选代码。软件验收日期为 2026-11-13。

| 配置 | 已取得的证据 | 仍需现场验证 |
| --- | --- | --- |
| A1、A1 mini、P1S、X1 Carbon，0.4 mm，PLA，纹理 PEI | 本机正常 CLI 创建项目、CadQuery 构建、Blender 真实预览、官方 Studio 切片、独立刀路检查通过 | Bambuddy 队列接受、匹配设备作业、实际首层与成品 |
| X2D，0.4 mm，单主料 AMS | 既有官方模板检查、Mac Studio 助手与发送保护回归通过 | 新候选版迁移后具体作业的现场验收 |
| 其他型号、喷嘴、外挂或多喷头组合 | 可以读取已安装官方配置；具体发送能力由预检报告 | 对应配置的切片、供料和现场验收 |

`trial_only` 表示这份切片仍缺当前打印配置确认。`printer_contacted: false` 表示该验证过程未联系实体打印机。独立文件检查通过后，仍需当前设备、材料和具体任务批准。

Mac 和 Windows 使用同一队列接口实现。候选版云端结果、真实宿主和实体设备结果分别记录，旧版本 CI 结果不能作为当前提交的验证证据。工作台当前可用路线以“待打印”预检中的通道能力为准。

新机型录入包括型号、固件、喷嘴、打印板、AMS/外挂实际连接、可用材料和网络使用方式。设备支持的软件选项从安装的官方 Studio 配置读取，现场已装配件另按读回或用户确认记录。

首次接入与实际打印步骤见 [首次配置](ONBOARDING.md) 和 [发送指南](PRINTING.md)。
