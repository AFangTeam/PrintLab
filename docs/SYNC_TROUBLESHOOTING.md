# 打印历史与收藏同步排查

## 当前数据来源

| 页面或功能 | 当前来源 | 覆盖范围 |
| --- | --- | --- |
| 打印历史和图册 | Bambuddy archives 与 print-log | Bambuddy 已保存并可读取的记录，包含其捕获的外部任务 |
| 灵感收藏 | 本机 Library/References/favorites.json | 使用者或 Agent 已登记的收藏 |
| 安装前的云端打印历史 | 待接入 | 需要账号端历史读取及完整分页验证 |
| MakerWorld 账号收藏 | 待接入 | 需要实际账号、地区与收藏列表接入 |

记录、模型文件和预览图各有来源。历史中存在某次打印时，原始 3MF、当次切片和预览的可用性仍逐项核对。发布版的软件安装与空接口验收覆盖基础运行，既有账号的数据回填另需真实样本验证。

## 安装后原有功能消失

1. 记录打印机型号、固件、PrintLab 和 Bambuddy 版本，国内站或国际站，以及 Agent 改动过的设置名称与改动前后的值。
2. 在原来的 Handy、Studio 或 MakerWorld 中核对同一账号和地区，查看一条安装前的打印记录、一项已收藏模型。
3. 需要云打印和账号同步的使用者，按机型说明恢复先前可用的云连接与账号登录。网络模式调整由使用者确认，访问码变更后更新相应连接配置。
4. 检查 API key 的归属与用途。PrintLab 的专用读取 key 用于状态、材料和已有档案。已有同步工具的 key 按该工具要求恢复权限。
5. Bambuddy 的 Allow Cloud Access 对应账号云读取，Manage Library 包含模型导入。具体授权按已安装版本、账号归属和实际调用核对。[上游权限说明](https://wiki.bambuddy.cool/features/api-keys/)
6. 原应用有旧记录而 PrintLab 没有时，记录缺失来源与时间范围。当前发布版的云历史与账号收藏接入缺口需要功能实现，重复刷新或扩大打印控制权限无法补齐它。

## 验收方式

安装 Agent 让使用者各选一条旧云端打印记录、一项 MakerWorld 收藏，以及一条安装后的外部打印记录。记录原平台是否可见、工作台是否可见、来源 ID、时间与文件可用性。真实账号样本尚未读回时，安装报告明确记录待接入项。

报告问题时提供版本、机型、设置名称、脱敏错误码与缺失记录的时间范围。账号密码、访问码、API key 与登录 token 留在使用者自己的配置中。
