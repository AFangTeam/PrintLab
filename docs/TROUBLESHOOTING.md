# 打印与接续排障

先运行 `printlab --help`，用实际项目 ID 和任务 ID 读取 `context`、`status`、`materials` 与 `reconcile`。保留错误原文、切片 SHA、固件、通道和时间。下列经验来自现有 PrintLab 工作流及本轮集成验证，按适用条件使用。

| 现象 | 先核对 | 处理与完成证据 |
| --- | --- | --- |
| 工作台能打开，设备连不上 | Bambuddy 是否在线、设备 ID、网络路线、凭据权限、局域网可达性 | 按连接指南选择符合原有 Handy/Studio 使用习惯的路线，读回设备身份、连接和新鲜状态 |
| 安装后 Handy、收藏或云端行为改变 | 当前网络模式与安装前方式、Agent 是否误改权限 | 按用户原需求恢复连接设置。旧云端历史和账号收藏导入已移出范围，本地导入与后续记录继续使用 |
| 启动被拒绝或有 HMS 错误 | 错误码、固件、当前通道、是否已有任务 | 保存原始回执，按实际错误处理认证或设备问题，重新读状态。需要改设备设置时由用户作出相应选择 |
| 设备显示进度但未正常出料 | 实际载料顺序、首层前最后升温指令、切片材料和喷嘴映射 | 重新生成并检查新切片，保留旧失败包。使用者观察实际首层，记录是否出料 |
| 发送超时、页面断开或按钮重复点击 | `dispatch.json`、唯一队列 ID、设备任务名、状态时间 | 先 `reconcile` 查原任务。已尝试启动的任务保持单次发送，结果未明时继续查证 |
| 发送助手提示系统弹窗遮挡 | 当前桌面的屏幕读取确认提示、辅助功能和屏幕读取授权 | 使用者处理系统提示，再核验窗口。权限探针为 true 时仍可能出现系统确认；发送结果以任务回执和设备读回为准 |
| 发送助手找不到“关闭”或无法核验选项 | Studio 版本、界面语言、实际截图分辨率、按钮识别结果 | 保留具体错误与窗口证据。低密度截图重采样正在实测，合并或低置信度按钮会停止操作；Agent 修复适配后重验完整任务信息 |
| 上一盘取消后仍显示 FAILED | 旧任务是否确实取消、设备屏幕状态、板面和加热状态 | 保存取消证据。Bambuddy 清板只能处理其队列条件，设备状态另读回；新任务使用新切片和具体批准 |
| 材料、颜色、喷嘴或板型不匹配 | 实际槽位、料卷关联、切片预设、现场喷嘴和设备卡 | 更正当前事实与映射，重做受影响切片和批准。未知余量明确显示未知，按预检缺项补充事实 |
| Mike/Sarah 创建中断 | 共同工作空间、建立标识、宿主已有聊天及临时 ID | 找回实际 thread ID，继续登记和读回介绍，避免重复创建 |
| 新会话不知道当前作品 | 稳定项目 ID、`latest_session`、brief 和 decisions | 读取 `context 项目ID`，沿用最新版本与选图，结束时保存 `handoff` |

## 本轮修复过的集成问题

- 独立检查器曾固定使用 X2D。现在按切片的实际机型选择检查模型，四机型实际切片已验收。
- 官方刀路中的 `T1000` 会切换厂商工具编号空间。单喷嘴温度检查现保留可确定的唯一物理喷嘴映射。
- CAD 独立环境没有工作台的锁库。打印空间现在由工作台读取并作为构建输入传递，避免让 CAD 环境依赖整套工作台。
- Windows 角色读回可能使用反斜杠或绝对路径。登记时规范化为工作空间内的相对路径，并拒绝其他目录。

## 把经验留给其他会话

先在具体项目复盘写现象、设备/材料/版本、证据、采取操作、结果及适用条件。用户偏好保留原话。确认可复用后，通过 `workspace note lessons` 追加共享经验，携带来源、稳定请求标识和当前文档哈希。新的 Session 由 `context` 读取同一记录。

接口接通、任务被接受、首层正常、机器完成和实物验收分别记录。材料和零件效果由实物反馈补充。
